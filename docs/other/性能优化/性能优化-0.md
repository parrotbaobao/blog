如何进行性能优化
1、先确定目标，多快算快？
2、利用专业工具评估出网站的性能表现，比如
3、分析原因
4、技术改造，利用
5、迭代

性能优化大概方向
1、减少整体的加载时间：减小文件体积、减少HTTP请求、使用预加载
2、让网站尽快可用：首屏信息少、先加载首屏其他懒加载
3、平滑的交互性：使用css代替js动画、减少ui重绘
4、感知：加载动画、骨架屏
5、性能监控

一些性能指标
FCP（First Contentful Paint），首次内容绘制，指浏览器首次绘制来之DOM的内容的时间，比如文本、图片、非白色的canvas、svg

LCP(Largest COntentful Paint)，最大内容绘制，可视区中最大的内容元素呈现到屏幕上的时间，用于估算页面的主要内容对用户的可见时间，比如img、svg、video元素

FID（First Input Delay），首次输入延迟，从用户第一次页面交互到浏览器实际能够响应交互的时间

TTI（Time to Interactive），网页第一次完全达到可交互状态的时间点，最后一个长任务完成的时间点，可以连续相应用户动作

TBT（Total Block Time），总阻塞时间，度量了FCP和TTI之间的总时间，在该时间范围内，大于50ms的时间

CLS（Cumulative Layout Shift）,累计布局偏移

Speed Index，内容的填充速度
