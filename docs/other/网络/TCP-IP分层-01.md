1、应用层（HTTP/HTTPS）
HTTP/HTTPS → 浏览网页
SMTP/IMAP/POP3 → 发/收邮件
FTP → 文件传输
DNS → 域名解析

HTTP 首先构造一个请求报文，他只关心“我要和服务器说什么”，用操作系统的 Socket API，把这段报文交给传输层

```vbnet
GET /index.html HTTP/1.1
Host: example.com

```

2、传输层（TCP/UDP）
接到请求报文后，和服务器建立 TCP 链接，分成多个 TCP 段，加个源端口（浏览器临时端口，例如 51234）、目标端口（服务器 HTTP/HTTPS 端口，80 或 443）、序号、确认号、校验和，之后交给网络层

TCP：
可靠传输：保证不丢、不重、不乱序。
三次握手、四次挥手。
常用于 HTTP/HTTPS、邮件、文件下载。

UDP：
不保证可靠，丢了就丢了。
胜在速度快，延迟低。
常用于视频直播、语音通话、游戏。

3、网络层（IP）
网络层再加个头，源 IP（你的电脑，例如 192.168.0.2）、目标 IP（服务器，例如 93.184.216.34）生存时间 TTL，形成一个包，然后交给数据链路层，IP 不管端口号，它只关心“数据从哪台机器到哪台机器”

4、数据链路层
再加上信息，帧头、帧尾就是源 MAC 地址（你网卡的硬件地址）和目标 MAC 地址（网关/路由器的 MAC 地址），形成个以太网帧，然后通过物理层发送出去

5、物理层
将帧转化成电信号、无线电波、光信号，一跳一跳经过路由器、运营商、跨国骨干网再到服务器

6、到服务器后
数据链路层检查帧头、帧尾，确认是发给自己的，去掉帧头帧尾，得到 IP 包之后发给网络层
以此类推到应用层，最后返回 HTTP 响应报文，一个请求要经过 2 次以上步骤。

客户端 → 服务器

客户端：应用层 → 传输层 → 网络层 → 链路层（封装）

服务器：链路层 → 网络层 → 传输层 → 应用层（解封装）

服务器 → 客户端

服务器：应用层 → 传输层 → 网络层 → 链路层（封装）

客户端：链路层 → 网络层 → 传输层 → 应用层（解封装）
